# StudySpot AI — іске қосу нұсқаулығы

Бұл жоба StudySpot сайтына нақты AI чат көмекшісін қосады. HTML интерфейсі `public/index.html` ішінде, ал API кілтін қорғайтын сервер `server.js` ішінде.

## Маңызды
- API кілтін HTML, JavaScript, CodePen немесе GitHub ашық репозиторийіне жазба.
- API кілті тек сервердегі `OPENAI_API_KEY` құпия айнымалысында сақталуы керек.
- API қолдану ақылы болуы мүмкін; API платформасындағы тариф пен лимитті алдын ала тексер.
- Чат сұрақтары AI провайдеріне өңдеу үшін жіберіледі. Құпиясөз, жеке дерек немесе құпия ақпарат енгізбе.
- Броньдау және орындар — прототиптің демонстрациялық деректері; бұл код университеттің ресми бронь жүйесіне қосылмайды.

## Жергілікті іске қосу
1. Node.js 20 немесе одан кейінгі нұсқасын орнат.
2. Осы бумада терминал ашып, `npm install` орында.
3. `.env.example` файлын `.env` деп көшір.
4. `.env` ішіндегі `OPENAI_API_KEY` мәніне API кілтін енгіз. Бұл файлды ешкімге жіберме және репозиторийге жүктеме.
5. `npm start` орында.
6. Браузерде `http://localhost:3000` аш.
7. `/api/health` мекенжайы `{ "ok": true }` қайтарса, сервер қосылған.

## Хостингке жариялау
Бұл — Node.js сервері бар жоба. Тек HTML-ді CodePen-ге қою жеткіліксіз: CodePen серверлік `/api/chat` маршрутын іске қоспайды.
1. Осы жобаның барлық файлдарын Node.js қолдайтын хостингке орналастыр.
2. Хостингтің Environment Variables / Secrets бөлімінде `OPENAI_API_KEY` айнымалысын орнат.
3. Start command: `npm start`.
4. Node.js 20+ таңда.
5. Жарияланған сайтты ашып, чаттан тест сұрағын жібер.
6. `OPENAI_API_KEY` ешқашан браузер кодында көрінбеуі керек.

## Құрылымы
- `public/index.html` — StudySpot сайты және AI чат интерфейсі.
- `server.js` — AI сұрақтарын OpenAI Responses API-ға қауіпсіз жіберетін сервер.
- `package.json` — тәуелділіктер мен іске қосу командалары.
- `.env.example` — құпия айнымалы үлгісі.
